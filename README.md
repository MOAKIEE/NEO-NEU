# NEO NEU

NEO NEU 是面向东北大学学生的第三方 Android 校园信息查询应用，并非学校官方客户端。应用采用 Android 原生 Kotlin、Jetpack Compose 与 Miuix 组件库构建，通过学校门户与本科教务系统读取数据并缓存在本机。认证由用户在学校官方网页自行完成，应用不接管、不保存学校账号密码，也不部署自建服务器。

## 项目范围

- 仅提供只读查询，不包含任何学校端写操作。
- 认证入口使用学校官方 HTTPS 页面，应用不注入脚本、不读取网页表单、不自动提交密码。
- 查询结果保存在应用私有缓存中，离线时可查看上次成功数据。

## 功能

应用底部固定为今日、课表、查询、我的四个入口；成绩、考试、余额、消息、待办等页面从查询页、首页快捷入口或今日页进入。

| 功能 | 说明 |
| --- | --- |
| 今日 | 当前学期的今日课程、校园生活摘要、最近考试与待办摘要，以及登录与快捷入口 |
| 课表 | 学期与教学周切换、周课表、课程详情、校区与作息时间 |
| 查询 | 检索并进入各查询功能，按学习、校园生活、消息与事务、学校服务分类，支持名称、别名与拼音搜索 |
| 我的 | 账号与连接状态、检查连接、外观主题、首页布局、隐藏余额、退出并清除本地数据、关于 |
| 成绩查询 | 学期筛选、课程列表、原始成绩、官方绩点与成绩详情 |
| 考试安排 | 已安排与未安排考试的时间、地点、座位与说明（只读展示，不报名或签到） |
| 校园卡余额 | 一卡通卡片余额与数据时间 |
| 网费余额 | 校园网账户余额与数据时间 |
| 消息中心 | 消息列表、来源与时间、筛选与分页、正文查看 |
| 待办与申请 | 待办、已办与申请状态列表 |
| 作息时间 | 按校区列出节次与上课时间 |
| 学校服务目录 | 常用学校官方网页入口，由用户主动在浏览器打开 |
| 首页布局 | 调整首页快捷入口与摘要模块的显示与顺序 |

### 应用不提供的功能

- 选课、退课或课表确认。
- 支付、充值、挂失或生成支付码。
- 成绩复查、缓考、补考报名等申请提交。
- 考试承诺书确认、签到或签退。
- 向学校发送消息标记已读（阅读状态仅保存在本机）。

## 构建与安装

在仓库根目录执行以下命令，运行各模块单元测试并产出 Debug 安装包：

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug
```

其他平台使用 `./gradlew` 执行相同任务。构建产物为 `app/build/outputs/apk/debug/app-debug.apk`。

安装到已连接的设备：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## 使用说明

### 首次使用

1. 打开应用，在登录页选择「统一门户」或「教务系统」。
2. 在弹出的学校官方网页中自行完成登录。账号密码只在学校网页输入，应用不读取表单内容。
3. 登录完成后点击「完成登录，检查连接」。双域均可用时应用自动返回；仅一域可用时自动打开待登录的学校页面。
4. 返回后即可在今日、课表、查询、我的中查看数据。

登录页仅允许打开学校域名（`neu.edu.cn` 及其子域）的 HTTPS 页面，其他跳转会被拦截。登录状态按门户与教务两个域分别显示。

### 日常使用

- 打开应用、进入页面或手动刷新时，应用会获取最新数据。
- 无网络或认证失效时，页面保留上次成功数据并标注来源与同步时间；恢复可用后重新刷新。
- 在「我的」中可「检查连接」，查看统一门户与教务的可用状态。
- 更换学校账号前，请在「我的」执行「退出并清除本地数据」，再重新登录。

### 数据状态

数据加载中、无结果、失败与离线缓存会分别显示，不会用失败或空结果冒充有效数据。每张卡片独立刷新，单项失败不影响其他卡片。

## 应用内设置

| 设置 | 说明 |
| --- | --- |
| 外观主题 | 系统、浅色、深色三种模式，切换后立即生效并保留 |
| 首页布局 | 快捷入口、摘要模块的显示与顺序，以及默认隐藏余额 |
| 隐藏余额 | 遮罩校园卡与网费金额，跨页面联动 |
| 本机已读消息 | 仅记录本机阅读状态，不写学校服务端 |
| 退出并清除本地数据 | 清除学校会话与当前账号的本地缓存 |

## 数据与隐私

- 应用只向学校门户与教务发起只读查询，不执行任何写操作。
- 登录 Cookie 由系统组件保存，门户与教务分别维护；执行「退出并清除本地数据」会清除学校会话与当前账号的本地缓存。
- 应用不保存或自动提交学校密码，不绕过验证码或二次认证，不伪装官方客户端。
- 查询结果仅保存在本机，用于离线查看。

## 声明

NEO NEU 为第三方应用，不代表东北大学官方立场。使用前请遵守学校相关网络与信息系统管理规定。第三方组件遵循其各自许可证，发布时保留适用的许可证与版权声明。

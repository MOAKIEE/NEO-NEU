# 接口参考

更新日期：2026-09-25。这里仅记录正式应用的查询边界与数据口径。学校网页接口不是稳定的公开 API；实际白名单由 `data/network` 的 `SchoolCall` 定义，页面只使用 `core/contract` 的 Repository，不直接拼接学校 URL 或处理 Cookie。

## 认证与请求边界

- 用户在学校官方 HTTPS 页面自行认证；门户和教务分别验证连接状态。已建立的一域会话不能证明另一域可用。
- `SchoolCall` 限定主机、路径、方法和参数名。部分教务查询使用 POST 表单，但只执行读取；新增调用须先核对学校页面行为与实际响应。
- 网络重定向、登录 HTML、业务错误、离线及结构变化分别转换为查询错误。失败时可保留当前账号作用域内的旧缓存及最近成功时间。
- 不调用选课、支付、挂失、申请提交、课表确认、考试签到或学校端消息已读接口。用户主动打开的官方网页可能自行产生访问记录。

## 当前查询范围

| 来源 | 已接入的读取内容 | 已知限制 |
| --- | --- | --- |
| 本科教务 | 当前学期、学期列表、教学周、校区、节次、课表、成绩及详情、官方绩点、考试安排 | 非空考试、多校区和实践课程样本尚未充分核对；节次时间缺失时不能推断上下课时间 |
| 学校门户 | 校园卡和网费余额、门户消息、待办／已办／申请状态 | 余额项目 ID 按返回目录查找，不固定账号专属值；非空待办记录尚未验证，当前适配器会报结构变化 |

门户消息与教务消息是不同来源；当前只接入门户消息。学校端已读状态与本机阅读状态分开，查看消息不发送服务端已读写请求。官方绩点以学校返回值为准，不自行套用公式。成功空结果与查询失败分开处理。

## 证据与修改方式

已登录独立宿主曾验证上述多项查询；覆盖范围和待验收项见[验证状态](验证状态.md)。历史学校网页脚本、请求路径调查及设备采集记录仅在本机保留，不作为仓库构建输入。学校协议可能变化，修改适配器时应使用脱敏字段结构核对，并同步更新契约、解析器测试和验证状态。不要提交姓名、学号、成绩值、余额、密码、Cookie、票据或原始会话记录。

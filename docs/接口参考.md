# 接口参考

更新日期：2026-09-30。这里记录正式应用的查询边界、数据口径与官方网页入口。学校网页接口不是稳定的公开 API；门户和教务白名单由 `data/network` 的 `SchoolCall` 定义，e 码通读取由 `integration/ecode` 限定。页面通过 `core/contract` 的 Repository 查询，不直接拼接学校 URL 或处理 Cookie。

## 认证与请求边界

- 原生登录页收集学号和统一认证密码，使用 Android Keystore 与 AES-GCM 仅加密保存于本机。静默认证通过学校 WebView 的现有 Cookie 和官方登录脚本进行，验证码、短信发送及二次认证需要用户继续；门户和教务分别验证连接，已建立的一域会话不能证明另一域可用。
- 自动填表限定 `https://pass.neu.edu.cn/tpass/login` 的 `loginForm`、`un`、`pd` 和 `index_login_btn`，核验同源 POST action 后点击官方按钮，不复制学校 RSA 公钥或自建密码提交接口。2026-09-30 只读核对了[公开登录页](https://pass.neu.edu.cn/tpass/login)及其[当前官方脚本](https://pass.neu.edu.cn/tpass/comm/neu/js/login_neu.js?v=20260302)，登录后与验证码分支仍需真实账号验收。
- 保存的凭据绑定本机随机账号作用域。恢复成功后仅用门户返回的 `d.info.xgh` 与保存账号精确比较以确认可继续自动登录，不用于门户与教务的缓存身份迁移；字段缺失时暂停，账号不匹配时删除保存的凭据。可见学校表单允许换号，因此展示前轮换缓存作用域。
- `SchoolCall` 限定主机、路径、方法和参数名。部分教务查询使用 POST 表单，但只执行读取；新增调用须先核对学校页面行为与实际响应。
- 网络重定向、登录 HTML、业务错误、离线及结构变化分别转换为查询错误。失败时可保留当前账号作用域内的旧缓存及最近成功时间。
- 不调用选课、支付、挂失、申请提交、课表确认、考试签到或学校端消息已读接口。用户主动打开的官方网页可能自行产生访问记录。

## 当前查询范围

| 来源 | 已接入的读取内容 | 已知限制 |
| --- | --- | --- |
| 本科教务 | 当前学期、学期列表、教学周、校区、节次、课表、成绩及详情、官方绩点、考试安排 | 非空考试、多校区和实践课程样本尚未充分核对；节次时间缺失时不能推断上下课时间 |
| 学校门户 | 校园卡和网费余额、门户消息、待办／已办／申请状态 | 余额项目 ID 按返回目录查找，不固定账号专属值；非空待办记录尚未验证，当前适配器会报结构变化 |
| e 码通 | `/ecode/api/user-info` 只用于会话探测；`/ecode/api/qr-code` 返回动态码和同级有效时间 | 独立会话；动态码仅在内存展示，不使用旧缓存，禁止调用具有登记副作用的 `/register` |

门户消息与教务消息是不同来源；当前只接入门户消息。学校端已读状态与本机阅读状态分开，查看消息不发送服务端已读写请求。官方绩点以学校返回值为准，不自行套用公式。成功空结果与查询失败分开处理。

## 官方网页入口

固定入口集中在 `OfficialService`；应用内 WebView 与本应用官方登录页共享 CookieManager。充值、缴费和邮件操作均由学校网页负责。

| 功能 | 地址 | 依据 |
| --- | --- | --- |
| e 码通认证 | `https://ecode.neu.edu.cn/ecode/#/` | 官方 APK 入口与[学校前端脚本](https://ecode.neu.edu.cn/ecode/js/app.fa3a054d.js) |
| 校园卡充值 | `https://pay.neu.edu.cn/scardrecharge51264Z006.html` | [学校服务页](https://www.neu.edu.cn/sfrd/jzg.htm) |
| 网费充值 | `https://pay.neu.edu.cn/netdetails51247N005.html` | [学校服务页](https://www.neu.edu.cn/sfrd/jzg.htm) |
| 缴费服务大厅 | `https://pay.neu.edu.cn/drCasLogin` | [学校服务页](https://www.neu.edu.cn/sfrd/jzg.htm) |
| 学生邮箱 | `https://mails.neu.edu.cn/` | [学校学生服务页](https://www.neu.edu.cn/sfrd/xs.htm) |

e 码通的已登录响应形状和只读边界见[校园服务接口验证](校园服务接口验证.md)；这些历史证据不代表当前正式 App 已通过扫码验收。

## 证据与修改方式

已登录独立宿主曾验证上述多项查询；覆盖范围和待验收项见[验证状态](验证状态.md)。历史学校网页脚本、请求路径调查及设备采集记录仅在本机保留，不作为仓库构建输入。学校协议可能变化，修改适配器时应使用脱敏字段结构核对，并同步更新契约、解析器测试和验证状态。不要提交姓名、学号、成绩值、余额、密码、Cookie、票据或原始会话记录。

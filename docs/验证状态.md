在仓库根目录运行 `./gradlew testDebugUnitTest :app:assembleDebug`（Windows 使用 `.\gradlew.bat`），再执行 `git diff --check`。涉及页面或会话时，在设备上复现相关登录、离线、旧缓存、空结果和失败状态。记录设备、系统版本、测试日期及未覆盖场景；不要提交个人响应值、Cookie、票据、原始 HAR 或截图中的个人信息。

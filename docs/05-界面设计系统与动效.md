# 界面设计系统与动效

更新日期：2026-09-23。本文件描述 `core/ui` 的设计令牌、通用组件与动效约定，供新增页面和后续维护使用。页面行为与数据口径见[前端说明](handoff/frontend.md)，当前验证进度见[验证与发布清单](04-验证与发布清单.md)。

视觉参考：[THU Info 仓库](https://github.com/thu-info-community/thu-info-app)。只参考信息组织、卡片层级与课程配色思路，不复制其品牌素材、源码或学校业务能力；本项目保持 Kotlin + Compose + Miuix。

## 分层

```text
core/ui/theme      设计令牌：颜色、动效、圆角、间距、主题映射
core/ui/components 通用组件：卡片、分组、列表行、筛选、分段、状态面板、动效工具
core/ui/timetable  业务组件：课表网格、课程详情抽屉
app/feature/*      页面：只负责数据装配与内容编排，不再自定义配色与圆角
```

硬性约定：

- 颜色、圆角、间距、动画曲线一律取自 `CampusTheme.colors` / `CampusShapes` / `CampusSpacing` / `CampusMotion`，页面内不写魔法数字。图标统一使用 Miuix 图标库，不引入 Material Icons。
- 组件库固定 Miuix，基础控件优先复用项目封装；课表网格等业务组件用 Compose 自定义布局。
- 深浅色、大字体与数据状态（加载／失败／空／旧缓存）与视觉同步维护。

## 颜色令牌（CampusColors）

| 分组 | 字段 | 用途 |
| --- | --- | --- |
| 表面 | `background` `surface` `surfaceElevated` `surfaceMuted` `surfaceSunken` | 页面底、卡片、高亮卡片、凹陷容器 |
| 文本 | `textPrimary` `textSecondary` `textTertiary` `textDisabled` | 标题、说明、元信息、禁用 |
| 描边 | `outline` `outlineVariant` `divider` | 卡片描边、弱描边、分割线 |
| 品牌 | `brand` `onBrand` `brandContainer` `onBrandContainer` `brandBorder` `brandPressed` | 主操作、选中态、品牌浅底 |
| 主视觉 | `heroStart` `heroEnd` `heroSurface` `onHero` `heroOverlay` `heroGradient` | 首页主课程卡与身份卡渐变 |
| 语义 | `success` `warning` `error` `info` 及各自的 `*Container`／`on*Container` | 状态提示与状态卡 |
| 功能辅色 | `timetable` `grade` `exam` `card` `network` `message` `olive` `brick` 的 `Foreground`／`Container` | 快捷入口、课程块、摘要卡 |
| 其他 | `scrim` `shadow` `isDark` | 弹层蒙层、卡片阴影、深色判断 |

课程颜色由 `courseColor(key)` 与 `courseAccent(key)` 提供：以课程记录标识或「校区 + 课程名」做稳定哈希，跨周、跨页面保持一致，深浅模式自动适配。八组色对保证同屏可区分。

`ThemeManager` 把上述色值完整映射进 Miuix `Colors`（含 `surfaceContainerHigh`、`windowDimming`、`disabled*` 等槽位），避免上游默认蓝色与项目品牌色混杂。

## 动效令牌（CampusMotion）

| 项目 | 取值 |
| --- | --- |
| 时长 | `instant` 120ms、`short` 180ms、`medium` 260ms、`long` 360ms、`layout` 300ms |
| 缓动 | `standard`、`emphasizedDecelerate`（进场）、`emphasizedAccelerate`（退场）、`smooth` |
| 预设 | `standard<T>()`、`enter<T>()`、`exit<T>()`、`springBouncy<T>()`（触达回弹）、`springSmooth<T>()`（尺寸收敛） |
| 交错 | `staggerDelay(index, step = 40ms, max = 240ms)` |

约定：高频操作只用 `instant`—`medium`；页面与主视觉用 `long`；按压、勾选等触达反馈用 `springBouncy`。

### 按压反馈的正确写法

`tapScale` 的缩放层位于裁剪层外侧，因此会把「整个视觉块」一起缩放。推荐把圆角交给它，背景与内容写在后面：

```kotlin
Box(
    modifier = Modifier
        .tapScale(onClick = onClick, pressedScale = 0.97f, clipShape = RoundedCornerShape(CampusShapes.large))
        .background(colors.surface)
        .padding(CampusSpacing.md)
) { /* … */ }
```

若把 `.clip(...)` / `.background(...)` 写在 `tapScale` 之前，缩放只会作用于内部内容，背景不动，看起来像布局错误。`clipShape` 同时保证 Miuix 的矩形按压高亮被圆角裁掉，不会出现方角溢出。

## 页面结构与转场

主框架（`MainScreen`）负责三件事：

1. 底部四项导航（今日／课表／查询／我的），使用 Miuix 图标与品牌选中色。
2. 一级路由转场：进入二级页面从右侧滑入，返回主框架淡出并轻微右移。
3. 标签转场：按标签左右顺序轻微横移 + 淡入淡出，避免大幅横向滑动。

每个标签与详情路由使用独立的 `SaveableStateHolder` 状态槽，切换不丢失滚动位置与筛选条件。

### 可折叠标题栏

页面大标题必须随内容滚动收起，不能长时间固定占位。三处写法必须成对出现，缺一处折叠会静默失效：

```kotlin
val pageScrollBehavior = MiuixScrollBehavior()
Column(
    modifier = Modifier
        .fillMaxSize()
        .background(colors.background)
        .nestedScroll(pageScrollBehavior.nestedScrollConnection)
) {
    CampusTopBar(title = "成绩查询", subtitle = "官方原始成绩与绩点", scrollBehavior = pageScrollBehavior)
    // 正文中的 LazyColumn / verticalScroll 驱动大标题收起
}
```

`CampusTopBar` 的 `color` 固定取页面背景色：若标题栏用 `surface` 而页面用 `background`，状态栏区域与标题栏之间会出现一条横向色带断层。

## 布局与内边距约定

这些是实际在模拟器上暴露过的缺陷，新增页面请一并遵守。

| 约定 | 原因 |
| --- | --- |
| 不在 `Scaffold` 上额外加 `statusBarsPadding()` | Miuix `Scaffold` 的 `contentWindowInsets` 与 `TopAppBar`、`NavigationBar` 自身的 `defaultWindowInsetsPadding` 已计入系统栏，再叠加会出现约 128px 的重复顶部留白 |
| 子页面正文不再加 `navigationBarsPadding()` | 底部安全区已随 `Scaffold` 的 `paddingValues` 下发；只保留 `imePadding()` 处理键盘 |
| 页面底色只由 `Scaffold` / 根容器设置一次 | 避免半屏 `background`、半屏 `surface` 的分层底 |
| 整块宽表（如课表网格）用圆角卡片承载 | 白色表体直接铺满会与页面底色形成生硬直边 |
| 底部信息条用页面底色 + 分隔线，不用 `surface` 铺满 | 否则会与底栏 `surface` 连成一条过厚的白带 |
| 大号数字占位不要用 `—` / `--` | 36sp 粗体下会被误读成图形；改用「暂无数据」小字，见 `AnimatedNumber` 与成绩页 |
| 输入框图标用 `CampusSearchField`，不要直接把图标塞进 `TextField` 的图标槽 | Miuix `TextField` 的 `leadingIcon` / `trailingIcon` 槽位自身没有内边距，直接放图标会贴住输入框边缘 |
| 占位文字在聚焦时需要隐藏 | Miuix `TextField` 在「内容为空」时把占位文字画在输入起点，光标也在同一点，两者会叠在一起；`CampusSearchField` 已在聚焦且为空时清空 label |

## 界面核验方式

模拟器实拍仅作为一次性核对手段，截图不入库：仓库不保存二进制截图，避免历史膨胀与无关文件混入审查。复现命令与本次核对范围见[验证与发布清单](04-验证与发布清单.md)。

核对时按下列顺序取值，比按截图估算点击位置可靠：

1. `adb shell am start -n <包名>/<Activity>` 拉起应用，并先确认前台包名确实是被测应用（`dumpsys window | grep mCurrentFocus`）。
2. `adb shell uiautomator dump /sdcard/ui.xml` 取控件真实坐标与文本，再据此计算 `adb shell input tap` 的位置。
3. `adb exec-out screencap -p > shot.png` 取当前帧；冷启动后需等待状态稳定再截图，否则会截到交错入场的中途帧。
4. `adb logcat -d -b crash` 查崩溃，`logcat -d | grep FATAL` 查异常。

Windows 上调用 `adb` 时不要给 `gradlew` 之类脚本设 `MSYS_NO_PATHCONV=1`，否则 wrapper 的类路径会被破坏；需要禁用路径转换时只对 `adb` 单独设置。

## 页面视觉骨架

各主页面统一按以下顺序编排，差异只在业务内容：

```text
大标题 / CampusTopBar
状态提示条（会话失效、旧缓存）        AnimatedVisibility
主视觉卡或统计卡                      HeroCourseCard / 统计渐变卡
快捷入口或筛选                       QuickActionRow / CampusFilterChip
分组区块                            CampusSection + CampusGroup / CampusRow
底部来源                            SafeDataTag
```

二级页面保持「主卡 → 分组信息 → 来源」三段式，列表首屏用 `StaggeredAppear` 逐项入场。

## 扩展方式

- 新增功能入口：沿用 `FeatureRegistry` 的稳定 ID 与现有 `AppDestination` 路由，图标取自 Miuix 扩展图标集，配色取自功能辅色。
- 新增页面：`CampusTopBar` + `CampusPageEnter` 包住内容，卡片一律走 `CampusCard` / `CampusGroup`，列表项走 `CampusRow`。
- 新增状态：在 `LoadStatePanel` 内扩展，保持「加载／失败／空」三态可区分，不把失败渲染成 0 或空集合。
- 升级 Miuix：实验性 API 只在本层封装内使用；升级后需重新编译并逐页检查抽屉、弹层与分段控件。

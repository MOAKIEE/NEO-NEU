# NEO NEU · 项目文档

更新日期：2026 年 9 月 23 日。

开发顺序：**后端数据接入 AI 先完成工程骨架、认证、查询、缓存和共享契约，交接后前端 AI 再实现原生页面**。具体职责和启动提示词见第 05 份文档，不并行开工。

**项目名称：NEO NEU。** Android 原生 Kotlin + Compose + Miuix，面向学生，优先满足本科生自用；第一版主要查询课表、成绩、考试、校园卡与网费余额、消息和待办，不实现充值、选课、挂失或申请提交。

**界面硬性要求：全部核心查询页面使用 Compose + Miuix 原生渲染，不做 WebView 套壳，不把学校网页嵌入主页面。** 数据通过查询适配器取得并转换为本地模型。网页只可用于必要的官方认证，以及用户主动选择的“在浏览器查看原文”；官方认证结束即返回原生页面。接口未打通的功能应标为未完成，不得用嵌入网页冒充已实现。

## 研究进度

2026-09-23 更新：Android 数据工程、官方认证宿主、只读适配器和 Room 缓存已建立。用户在官方页面登录后完成两域会话探针，以及课表、历史成绩、空考试、余额、消息、空待办的真实查询；离线与认证失效后的旧缓存保留和恢复也已验证。非空考试／待办、多校区、实践课程等限制见 [数据层交接](handoff/data.md)。

已完成 APK 静态解析、Miuix 源码与 Maven 制品检查、现有浏览器登录态下的门户／新教务／一卡通／缴费大厅／消息中心页面检查，以及这些页面使用的公开 JavaScript 研究。没有输入或收集学校密码，没有执行付款、选课、挂失、课表确认或申请提交。

早期研究阶段已取得网页代码证据；后续 Android 验证宿主已对主要查询取得真实响应并只记录脱敏字段结构。并非所有接口或非空业务形态都已验证，证据级别以 03 文档和交接清单为准。

个人姓名、学号、具体成绩、余额、Cookie 和票据不写入交付文档。必要的原始脚本与核验材料位于项目 `research/`，用途见 [研究材料说明](../research/README.md)。过时初稿及临时研究文件已删除。

当前需求和实现方向以本索引列出的六份文档为准；01 定义范围，06 细化并作为页面布局依据。`research/` 仅用于追溯证据，不是待实现功能清单，也不是可直接运行的 App 源码。

## 维护规则

- 同一事实只在所属文档维护，其他文档使用链接；构建入口见[项目 README](../README.md)。
- 产品目标、代码实现、历史实测分别描述；编译成功、合成测试或旧版截图不代表当前页面验收通过。
- 接口参考只记录当前应用的查询边界；公开脚本不能替代真实响应样本。
- 修改功能时更新开发指南；修改组件约定时更新界面规范；完成验证时更新验证状态并注明范围。
- 历史设备日志与实施过程仅在本机保留；[research](../research/README.md) 记录公开或脱敏的追溯材料。

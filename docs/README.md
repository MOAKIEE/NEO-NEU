## 维护规则

- 同一事实只在所属文档维护，其他文档使用链接；构建入口见[项目 README](../README.md)。
- 产品目标、代码实现、历史实测分别描述；编译成功、合成测试或旧版截图不代表当前页面验收通过。
- 接口参考保留研究时间与证据等级，公开脚本不能替代真实响应样本。
- 修改功能时更新开发指南；修改组件约定时更新界面规范；完成验证时更新验证清单并注明范围。
- 历史方案通过 Git 查阅，不再新增“本轮重构”“交接 v2”等平行文档。[research](../research/README.md) 仅保存追溯材料。

# 登录流程

更新日期：2026-09-30。业务仍为只读查询；登录凭据仅保存在本机，不部署账号服务器。

## 用户操作

首次点击登录时展示原生 Miuix 页面，填写学号及学校统一认证密码后点击「保存并登录」。密码框有遮罩，不将输入写入 Bundle、SavedStateHandle、Room 或日志；旋转时只在 ViewModel 内存保留，进程终止后不恢复密码文本。登录窗口设置 `FLAG_SECURE`，学校 WebView 不保存表单状态，不参与系统自动填充。

正常认证全部在不可见的学校 WebView 中完成，先打开官方门户或教务入口，复用 Cookie/CAS 会话。停留在已核对的密码表单时，自动填入本机保存的凭据并点击学校原有按钮，保持学校的当前加密与提交行为。每轮最多一次自动提交；提交前将保存凭据置为暂停，以免进程异常终止后盲目重试。

出现可见验证码、短信验证或其他未知学校交互时，原 WebView 从不可见容器移到学校验证页，不重载，不重新发起密码提交。验证码、短信发送、设备授信全部由用户在官方页面操作。完成后分别复验门户和教务，尝试连接另一域，再返回原查询位置。仅门户可用时可手动选择仅连接门户返回；未连接的服务仍独立提示。

学校拒绝账号密码时回到原生输入页并暂停自动提交。网络、TLS 和超时失败分别保留错误，自动恢复不会把暂不可达等同于需要再次提交密码。用户仍可使用「使用学校网页登录」，此入口删除保存凭据并轮换缓存作用域。

## 实现分层

| 位置 | 职责 |
| --- | --- |
| `OfficialLoginActivity` | 原生输入、连接进度、错误及可见学校验证；ViewModel 在旋转时持有验证网页 |
| `SchoolLogin` / `LoginBrowser` | 串行静默尝试、受限网页、单次提交、30 秒超时、同一个 WebView 的内存交接 |
| `school-login.js` | 只返回固定状态，检查 DOM、验证码与表单 action；不返回账号、密码、错误原文或网页内容 |
| `LocalSession` / `SavedSchoolCredentials` | Cookie 写入与凭据操作共用锁；账号作用域、加密保存、暂停及退出清除 |
| `SessionProbe` | 原有两域业务探针，恢复后只在内存核对门户账号字段 |
| `MainActivity` / `AutomaticLoginGate` | 前台失效自动恢复，每个作用域／域 60 秒冷却，交互失败等待用户操作；成功后重放当前页面查询 |

打开原生表单不改变会话。提交新凭据时删除旧 Cookie 并轮换随机账号作用域；静默恢复保留作用域及当前缓存。可见学校表单允许用户改号，因此转为可见前轮换作用域并隔离旧缓存，保留 Cookie 和验证页面。退出撤销作用域、删除保存凭据及其 Keystore 密钥，再清理 Cookie 和当前账号缓存；旧作用域的请求与验证结果不能重新保存凭据。

不可见尝试仅在应用前台运行，切到系统后台时取消并销毁其 WebView，不启动常驻服务或定时密码任务。后续回到前台仍可复验有效会话，需要时按恢复门限尝试。等待用户继续的浏览器仅通过随机内存 token 交接，Intent 不携带密码、Cookie 或完整学校 URL；未领取的浏览器两分钟后销毁。旋转保留当前可见 WebView；进程被终止后需要重新打开学校验证。

原生凭据表单可以滚动，适配大字体和横屏。验证页在高度受限时收起提示及连接摘要，优先保留学校网页；键盘占据大部分空间时暂时隐藏原生分段和检查按钮，学校自身的表单提交与成功后的自动复验仍可继续。

## 凭据保护和校验

Android Keystore 生成不可导出的 AES-256 密钥，AES-GCM 每次使用新的 12 字节 IV，带固定版本 AAD 与认证标签。私有 SharedPreferences 只持久化密文和暂停标志；绑定作用域、学号、密码都在密文内。缺失或失效的密钥、损坏的密文不能退回明文保存；应用备份保持禁用。

自动填表仅允许精确 origin `https://pass.neu.edu.cn` 与路径 `/tpass/login`；原生 URL 和执行脚本内同时校验，表单必须是同源的 POST 登录 action，账号密码输入必须属于该表单，拒绝外部 action、其他端口或表单 target。JS 参数使用字符串转义，网页侧只点击官方 `index_login_btn`，不复制 RSA 公钥或自行重建认证协议。学校其他网页即使在 `neu.edu.cn` 下也不会得到保存的密码。

恢复成功后将保存账号与门户返回的 `d.info.xgh` 精确比较，一致时启用后续自动提交，不匹配时删除凭据，字段缺失或暂不可达时暂停。这是单个已观察门户字段的保守校验，不声称已验证所有账号类型，也不用于合并门户和教务缓存身份。旧账号、字段缺失或结构变化不会自动重新启用保存密码。

## 验证

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug
node integration/auth-web/src/test/js/school-login.test.cjs
git diff --check
# 已连接专用测试设备时，测试库自己的隔离 APK，不使用学校网络账号：
.\gradlew.bat :data:session:connectedDebugAndroidTest :integration:auth-web:connectedDebugAndroidTest
```

JVM 回归覆盖密文往返、随机 IV、篡改和错误密钥、截断和版本拒绝、凭据诊断脱敏、JS 参数转义、重复恢复门限、账号作用域切换及既有双域登录步骤。DOM 测试用合成表单覆盖一次提交、验证码和二次验证、隐藏模板、密码拒绝、表单导航后不重试、精确 origin/path 及 action/target 防护，不向学校发送测试密码。

学校登录后、验证码与二次认证的真实设备结果仍需用户账号验收；页面变化会回退到可见学校页。当前公共页面依据为[学校登录页](https://pass.neu.edu.cn/tpass/login)和[官方登录脚本](https://pass.neu.edu.cn/tpass/comm/neu/js/login_neu.js?v=20260302)。历史会话记录及真实密码不进入仓库。

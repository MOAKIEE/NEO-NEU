## 待补真实样本

- **考试**：目前仅有空列表样本。获得本人非空考试时核对时间、地点、座位、状态和详情；不以演示数据宣称通过。
- **待办与申请**：目前仅有空列表样本。非空记录会被适配器标为 `SCHEMA_CHANGED`；取得脱敏结构后再更新解析与 UI，并验证分页。
- **课表边界**：多校区、非空实践课程、单双周和临时地点变化尚未核对；节次起止时间与组合教师／周次描述也需验证。
- **成绩与消息**：历史成绩仅核对过一个学期；消息翻页、来源和已读筛选的其他组合仍需实际样本。
- **设备环境**：WebVPN／校外路径、跨账号切换、API 24 真机与不同系统 WebView 尚未验收。

## 正式 App 验收

- [ ] 全新安装后由用户在官方页面登录；返回原生页面并完成门户、教务双域复验。
- [ ] 在正式 `app/` 中逐页核对课表、成绩、考试、余额、消息和待办的真实数据、空状态、失败状态与更新时间；与学校页面逐项比对可见值。
- [ ] 杀进程重开、断网、认证过期后确认旧缓存只在当前账号作用域显示，恢复时正确刷新；退出后清理会话和当前作用域缓存。
- [ ] 切标签、进入详情和返回后保留筛选与滚动；复验旋转、进程恢复、Miuix 抽屉及确认框的返回行为。
- [ ] 320dp/390dp、字体 1.3/2 倍、深色、TalkBack、后台预览隐私、手势导航、键盘安全区及长列表／课表切周在目标真机上检查。
- [ ] 验证课程跨日、跨周、真实冲突及多校区列表；确认缺时间、过期数据不会生成确定性的课程状态。
- [ ] 使用 release 构建检查滑动、刷新和切页；确认网络及解析不阻塞主线程。
- [ ] 确认所有核心查询留在原生页面，学校网页只用于认证或用户主动打开原文；没有支付、选课、挂失、申请提交、课表确认、承诺书确认或服务端已读写请求。
- [ ] 发布前核对应用标识、签名、版本、隐私文案、第三方许可证与目标 Android 版本行为。

运行现有自动检查：

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug
```

`verification/` 可用于继续采集**脱敏的字段结构**，不可把姓名、学号、成绩值、余额、密码、Cookie、票据或原始 HAR 提交到仓库。正式 App 的真机验收应单独记录结果，不以此处历史验证宿主记录替代。

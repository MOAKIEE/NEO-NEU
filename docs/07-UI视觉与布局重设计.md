# NEO NEU 界面重设计方案 V2

日期：2026-09-23 · 状态：设计提案，尚未实现。

本文只交付界面布局与 UI 设计，不修改应用代码。以“有校园气质、重点鲜明、查询高效”为目标，继续使用 Kotlin / Compose / Miuix。新版设计经采用后，视觉和布局以本文为准；原 [06 页面布局设计](06-UI页面布局设计.md) 保留为 V1 基线，产品范围仍以 [01 产品设计](01-首版产品与交互设计.md) 为准。本文不表示数据能力或真机验收已经完成。

**UI 库要求（用户明确指定）：使用 Miuix。** 基础控件、主题、导航、卡片、设置项与弹层优先使用项目现有 Miuix 组件及封装；课表网格、时间轴等业务布局用 Compose 自定义实现，并沿用 Miuix 主题与交互。不以 Material / Material 3 控件替换整套界面，不迁移到 React Native、Flutter 或网页 UI。图标资产不等同于控件库，现有图标可按统一视觉规范整理。沿用当前固定版本，除非实际实现发现必要兼容问题，不为本次重设计主动升级依赖。

## 2. 整体视觉方向：清晰、有色彩的校园日常

首页打开后，首先看到一张深蓝课程卡；下方是轻量彩色快捷入口和清楚的课程时间轴。查询页像整理过的校园工具箱，成绩、考试最突出；课表通过稳定的课程配色形成辨识；我的页面有轻品牌感，设置保持安静。

全页约 75%—85% 为中性表面；品牌色集中在主卡、当前选中项和关键按钮，辅色用于图标容器及课程块。该比例是视觉审查参考，不作为像素统计指标。每页最多一个大面积强色区域；不使用满屏渐变、玻璃模糊和无数据意义的图表。

品牌图形使用由课表格、书页与字母 N 关系衍生的抽象几何线条。它是原创装饰方向，不暗示学校官方标识。仅出现在欢迎页、首页主卡的空余角落与关于页；不在普通列表重复出现。

| TextSecondary | #56647A | #B0BDCF | 地点、时间、说明 |

### 2.3 排版、尺寸和表面层级

| 项目 | 规范 |
| --- | --- |
| 字体 | 系统中文无衬线；不捆绑装饰字体；所有文字跟随系统缩放 |
| 主页面标题 | 28sp / 34sp 行高，Bold |
| 详情标题 | 20sp / 28sp，Semibold |
| 主卡课程名 | 22sp / 30sp，Semibold，允许两行 |
| 区块标题 | 18sp / 26sp，Semibold |
| 列表正文 | 16sp / 24sp；辅助信息 13sp / 20sp |
| 入口标签 | 14sp / 20sp；重要说明不使用 11sp |
| 主数据数字 | 32sp / 38sp；单位 14sp；成绩列表 24sp |
| 手机边距 | 左右 20dp；宽度小于 360dp 时 16dp |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32dp；区块之间 24dp |
| 圆角 | 主卡 24dp，普通分组 20dp，入口/课程块 12dp，标签 8dp |
| 图标 | 常规 24dp，入口图标底 48dp；触控目标至少 48 × 48dp |
| 阴影 | 普通分组无阴影；浮层与导航仅极轻层次；用表面差异建立主层级 |
| 分隔线 | 同组列表内 1dp，向文字起点缩进；最后一项不画 |

三种内容容器：A 类品牌主卡用于唯一主任务；B 类 Surface 分组承载列表；C 类浅色功能块用于余额和重点入口。区块标题原则上放在卡片外。连续列表放入一个分组，避免每行一张卡、卡内再套卡。

## 3. 导航与页面骨架

四个底部入口顺序不变，固定导航本体建议 64dp，额外叠加系统底部安全区。图标 24dp、标签 12sp，选中项显示 BrandContainer 胶囊和 Brand 图标/文字，未选项用 TextSecondary。禁止仅靠颜色判断选中状态。

主页面向下滚动后可收拢为 56dp 紧凑标题栏。详情页保留返回和名称，隐藏底部导航。每个主页面保留滚动、筛选、周次；返回成绩详情前的列表时保留搜索和滚动位置。

页面关系保持：今日 → 课程抽屉/成绩/考试/余额/消息；课表 → 课程抽屉/周次/校历作息；查询 → 原生功能/官方服务说明；我的 → 连接/外观/首页/隐私/关于。

### 4.2 关键布局规则

标题区约 68dp，标题下的日期为 TextSecondary。消息按钮用 Surface 圆形底，点击面积 48dp。未读只在范围明确时显示数量，否则显示点并提供可访问说明。

主课程卡默认最小高度 168dp、内边距 20dp，高度随课程名和字体增长。顺序是状态、课程名、时间、地点；地点保留可读空间，不放教师和课程号。整卡打开详情，右下箭头只提示可点击，不另加重复按钮。

快捷入口位于主卡下方，无独立白卡外壳：图标上、标签下，四等列，默认前三项为成绩、考试、待办，第四项“全部”固定。每项以明确短标签定义名称，不使用字符串截取生成简称。

今日课程使用一个白色时间轴分组，时间列约 52dp、标记列 12dp、其余给课程。当前项使用品牌色标记及很浅的背景；已结束项只减弱状态文字，课程名称仍清晰。默认最多四项，超过时显示“查看全部 N 项”。主卡与列表允许重复同一课程，分别服务即时判断和全天浏览。

余额以两张等宽轻色卡呈现：校园卡绿、网费青，金额用 TextPrimary，不整块深色。余额眼睛按钮的触控范围至少 48dp。数据时间分别显示“最近同步”，只有真实提供学校更新时间才写“学校更新于”。

390 × 844dp、标准字体的首屏目标：完整标题、主卡、快捷入口及至少两条短课程。此目标包含系统栏与底部导航，需要后续实机验证；长文本和大字体优先可读，允许自然滚动。

### 4.3 主卡状态

| 数据条件 | 主卡表现 |
| --- | --- |
| 可信时间显示正在上课 | “正在上课”，保留课程和时间；不用秒级倒计时 |
| 今天还有已确认课程 | “下一节课”及时间地点 |
| 当日已结束 | “今天的课程已结束”；仅在明日数据可信时附首课信息 |
| 成功获取且当日无已安排课程 | 浅蓝主卡：“今天没有已安排课程”，动作“查看本周”；不等同没有未排课程 |
| 缺少可信时间 | “今日课程”及第 X—Y 节；不判断正在上课，不猜测开始时间 |
| 学期/周次尚不能确认 | “教学周待确认”，保留选择学期入口；不能取第一周冒充本周 |
| 同时多项课程 | “同时有 N 项安排”，点击进入选择列表，不静默挑选一项 |
| 无缓存且失败 | 同位置紧凑错误内容及重试，不显示“今天没课” |
| 有旧缓存 | 保留内容，“上次同步课程，可能已变化”；不以旧时间生成强确定性的当前状态 |

标题、状态区、主卡、底部导航固定；快捷项和其余摘要沿用本地配置。最近考试/待办成功为空时不占大卡片；启用的模块加载失败时仍显示紧凑提示，不通过隐藏模块制造“没有事项”的错觉。

## 5. 课表：颜色稳定、网格清楚、控制区紧凑

```text
课表                               [周 / 日] [⋯]
[2026—2027 秋季 ▾]                [全部校区 ▾]
[‹]         第4周 · 9/21—9/27             [›]
                                     回本周
        周一     周二     周三     周四    →
         21       22      [23]      24
  1    ╭──────╮         ╭──────╮
       │英语  │         │物理  │
  2    │B301  │         │A102  │
       ╰──────╯         ╰──────╯
  3             ╭──────╮
  4             │高数  │
                │A201  │
                ╰──────╯
                 …
[未安排课程 N 项 ›]     [实践课程：有可信数据时]
```

学期与校区放同一控制行，周次独立一行；大字体时控制项自然换行。“回本周”仅在偏离本周时出现，但不能挤掉日期范围。周次左右按钮各 48dp。周末始终可访问。

网格采用白色/深色表面，日期头与左侧节次轴固定。单日列最小宽度 64dp，左轴 40—52dp；七列不足时横向滚动日期区，边缘显示后续列提示。横拖只滚列，切周使用按钮或周次抽屉。禁止缩小到七天都挤进窄屏。

课程颜色共六组：蓝、紫、青、绿、橙、玫瑰，沿用功能色表的前景/容器组合；在课表中颜色只用于区分课程身份，不表示成绩或课程性质。按可靠课程标识稳定映射，同门课跨周一致；不可用时根据可重复的课程组合键映射，不按列表顺序随机换色。

课程块 12dp 圆角、6—8dp 内边距、窄色边条。名称 13sp、教室 12sp，至少两行名称空间；空间不足时转集合入口或提供每日列表，不无限缩字。实验、跨校区用文字标签。单节格建议最小 52dp，但按内容增高，课块高度表达节次数，不暗示未经确认的分钟长度。

冲突课程优先集合卡“2 项安排”，展开后逐项进入详情；不覆盖底下课程。节次轴缺少起止时间时只显示节次。校区作息不一致且无法对齐时，“全部校区”显示按校区分组的每日列表，并说明“各校区作息不同，已按校区展示”。

课程详情继续用底部抽屉，默认按内容展开，可扩展到全高。顶部细色条与课块同色，依次展示课程名、日期/节次、时间地点、教师、原始周次说明及其他安排。未拆分的教师/周次原文作为“学校安排说明”展示，不强行拆出不存在的结构化字段。

```text
在浏览器中查看学校提供的服务
```

成绩与考试使用两张浅紫/浅橙重点入口，最小高度 124dp，图标置上，名称 16sp，说明 13sp，取消窄卡内部的横向图标挤压。它们只展示用途，不为入口额外请求 GPA 或考试数。

常用工具使用一个 Surface 分组，三列、每项最小高 88dp、图标 48dp + 完整标签；六项时形成两行，不给每个图标再套完整卡片。将来超过九项时按学习、生活、信息分组，每组首屏最多六项，其余“查看全部”。未接入的“我的日程”不进入默认常用面板；在全部功能中说明状态。

搜索只查注册的功能名称/别名/用途，结果单列展示，保留类别与接入状态；无匹配显示清除关键词。键盘出现不遮住最后一个结果。用户存在本地收藏时，在重点入口后展示“我的常用”，最多两行，重复的普通入口可从工具面板中收起，搜索始终完整。

学校服务为独立列表入口，标注“官方网页”，进入服务说明后由用户主动打开浏览器。未接入项用中性状态标签，点击解释能力；不能把锁图标误用成会员功能提示。

## 7. 成绩、考试与余额的页面设计

### 7.1 成绩：大数字统计 + 紧凑课程列表

顺序：紧凑标题栏 → 浅紫统计卡 → 学期选择/排序 → 本地课程搜索 → 成绩分组列表。

统计卡左侧“官方总平均学分绩点”，下方 32sp 数据；底部“学校返回统计值 · 最近同步 …”。右侧只保留成绩单几何图形，不加趋势箭头。未明确范围时不写“全学程”或“本学期”。统计与成绩列表独立加载，任一失败不遮挡另一项。

成绩行采用左右结构：左侧课程名 16sp，下一行学分/性质，必要时第三行学期；右侧 24sp 原始成绩，下面 13sp 官方绩点。等级制文字与数字同级，不换算、不按红绿标高低。重修状态用中性小标签。

详情页顶部是课程名和原始成绩，下面分为“课程信息”“学校提供的成绩组成”“其他认定信息”。成绩组成默认用字段列表；缺乏权重时不画饼图或进度条。空学期提示“该学期暂无成绩”，保留其他学期选择。

### 7.2 考试：日期分组与清晰地点

顺序：标题 → 学期 → 已安排/未安排分段 → 日期分组列表。卡片上缘显示日期、时间，主体课程名 18sp，下面地点，末行座位与原始状态。日期可用浅橙 48dp 小标记，不做大幅倒计时。

有可信结构化时间才排序和判断“已结束”；只有官方描述时按原文呈现，保留来源顺序。地点“尚未公布”只用于已确认未公布；不明原因缺失写“未提供地点”。有条件限制时解释并提供官方处理入口，不代为确认承诺书。

详情延续卡片的信息顺序，说明文字完整显示。非空考试仍待真实样本验证，本设计是渲染目标，不改变现有验证结论。

### 7.3 余额：一张有质感的信息卡

标题 → 轻绿/轻青余额卡 → 来源与数据说明。卡内顺序：图标与名称、金额/遮罩、币种或单位、最近成功同步。金额 36sp；隐藏显示固定“••••”，不泄露位数。眼睛按钮遵循全局偏好，进入详情不会自动显示金额。

客户端隐藏、学校返回遮罩、无数据是三种状态：分别写“已隐藏”“学校未提供明文余额”“暂未获取余额”。无数据不得显示 0；失败保留可信旧值和提示。不设置臆测的低余额红线，不加入消费曲线或总资产。

只有余额也允许页面留白，用合理位置与字号形成完整页面，不以占位图表填充。

## 8. 消息、待办、校历与我的

### 消息中心

标题下保留来源与学校已读筛选，只有已接入来源可选择。正文列表放同一 Surface 分组：40dp 来源图标、标题最多两行、发送时间、简短摘要。未读以文字/小点和标题字重共同区分。功能色玫瑰用于来源图标，真正错误才用 Error。

详情采用阅读页：24sp 标题、13sp 来源/时间、16sp 正文及适当段距；当前消息数组按受控纯文本展示。底部是“查看官方原文”和访问可能改变学校状态的说明。本机看过和学校已读分开，不提供全部已读按钮。

### 待办与申请

待办/已办/我的申请分段导航，单组列表，业务状态在标题下显示，不画未经提供的审批流程图。当前非空记录会触发结构变化错误时，显示“学校数据格式暂不支持，暂时无法展示”，附重试及适用的官方入口；不能展示空状态或用演示记录填充。

### 校历与作息

顶部学期与校区筛选，下面“校历 / 作息”分段。校历采用教学周列表，当前周浅蓝突出；作息按节次逐行展示。接口未提供起止时间时，写明“学校当前未提供节次时间”，不使用通用大学作息填补。

门户个人日程尚未进入完成契约，因此默认查询页不新增可用日程入口；未来接入后再采用日期条 + 时间列表，与教务课程明确区分来源。

### 我的

顶部“我的”，下面轻蓝身份卡：56dp 通用头像、已验证姓名/身份、脱敏学号；没有可靠身份字段时显示“学校账号”，不造姓名、学院和校区。

身份卡下是一组门户/教务连接状态，分别用图标 + 文字，不以“已登录”掩盖另一域未连接。随后三组设置：

1. 显示：外观、首页设置、课表显示、余额隐藏。
2. 数据与隐私：缓存、清除本地数据、后台预览隐私。
3. 关于：应用版本、开源说明、功能接入状态。

普通行最小 56dp，图标底 32dp，右侧值和箭头对齐。退出独立置底，进入清理说明确认。外观设置展示跟随系统、浅色、深色三个小型界面预览；首页设置显示模块缩略结构、开关和上移/下移，沿用稳定模块 ID 保留已有偏好。

## 9. 欢迎、异常和数据可信度

欢迎页上方为原创 N 几何图形，中部“NEO NEU”和“课表、成绩与校园信息，随手可查”，下方三枚能力标签。底部一个主按钮“登录学校账号”和文本入口“了解数据使用”。登录继续进入官方认证页。取消后允许浏览功能目录，个人数据区使用统一未登录提示。

| 状态 | 位置与呈现 | 恢复方式 |
| --- | --- | --- |
| 首次加载无缓存 | 与最终结构相似的局部骨架；不填示例值 | 独立完成，各模块互不阻塞 |
| 刷新且有数据 | 保留内容，顶部轻刷新指示 | 完成后更新对应模块同步时间 |
| 更新失败且有缓存 | 对应模块底部短提示，缓存时间可见 | 局部重试 |
| 网络明确不可用 | 页头一条离线提示；模块保留各自时间 | 恢复网络后刷新 |
| 认证失效 | 一条域明确的提示，如“教务连接已过期” | 登录后回原页及筛选；缓存按会话作用域策略处理 |
| 无权限 | 当前功能说明“当前账号无法查看此项信息” | 保留返回和适用说明，不反复要求输入密码 |
| 数据结构变化 | “暂时无法展示学校返回的数据” | 重试、适用的官方入口；不把失败当空 |
| 成功空结果 | 图标 48dp + 一句范围明确的文案 | 提供切学期/日期等相关动作 |
| 暂未接入 | 中性状态标签和说明页 | 不提供无效重试按钮 |
| 演示 | 主页面和详情均保留“演示数据”标签 | 退出演示入口明确，不与真实来源混合 |

不要因为 isStale 就断言网络错误：可能是认证、格式变化或其他原因，提示依据具体错误类型。异常条优先级为认证/阻断性错误高于一般缓存提示，避免同一原因在首页重复出现四次。余额失败只影响余额。

已成功获取空列表与 data == null 严格区分。保留缓存也不等于可以跨账号显示；以当前数据层账号作用域和退出清理规则为准，不为视觉连贯复用身份未知的旧账号数据。

## 10. 自适应、无障碍与动效

| 场景 | 设计响应 |
| --- | --- |
| 320—359dp 窄屏 | 16dp 边距；重点双卡必要时单列；快捷区可 2×2；不裁剪名称 |
| 360—599dp 手机 | 默认布局；课表七天不足时横向滚动 |
| 字体放大至约 1.3 倍或文字已溢出 | 查询面板减为两列、余额纵向；最终按可用宽度和内容决定 |
| 字体约 1.5—2 倍 | 查询结果/设置单列；默认建议每日课表列表，可切回网格；文字不固定高度 |
| 600—839dp | 内容最大宽度约 720dp 居中，课表按宽度显示更多列 |
| ≥840dp | 今日可主课程/课程列表与摘要双列；详情正文最大约 680dp；课表优先完整七列 |

布局阈值为实现建议，需在分屏、横屏与系统字体设置下复核。底栏保持既有四入口，不因屏幕大小改变功能命名。

可访问性要求：正文目标对比度 ≥4.5:1，大字及必要图形 ≥3:1；课程颜色同时配合标题、地点和状态文字。TalkBack 对课程读出课程名、日期、节次、可用时间和地点；隐藏余额不可被朗读或作为可复制明文暴露。选中标签、消息点、眼睛按钮提供明确状态描述。

按压反馈约 100—140ms，页面/抽屉过渡约 200—280ms。切周直接更新网格并使用轻淡入，不整页飞入；已有缓存不闪回骨架。遵循系统动画设置，关闭动效时使用静态状态。首版不依赖 blur，不增加最低 Android 版本要求。

## 11. 组件落地建议与实施顺序

以下是后续实现分工建议，本次不新增这些组件或改动代码。

| 现有位置 | 设计上的改造职责 |
| --- | --- |
| core/ui 的 ThemeManager | 统一品牌、功能、状态、课程色及排版 token |
| QueryCard / 通用组件 | 分出主任务卡、列表分组、功能入口、余额卡、状态提示，避免一个卡片包所有内容 |
| TodayScreen | 主课程卡、无外壳快捷区、时间轴、分项余额与状态 |
| QueryScreen / FeatureRegistry | 图标面板、重点入口、完整短标签和统一图标颜色映射 |
| TimetableGrid / CourseDetailBottomSheet | 稳定课程色、固定坐标轴、冲突集合与缺时间降级 |
| 各查询详情页 | 共享筛选行、数据来源行、列表与字段分组 |
| MainScreen / 导航 | 标题折叠、导航选中态、安全区、返回时保留页面状态 |

实施优先级：

1. **P0：设计系统 + 今日 + 查询 + 导航。** 先形成可见的整体气质变化，同时统一深色模式。
2. **P1：课表 + 成绩 + 考试 + 余额。** 完成高频任务的视觉层级及真实数据降级。
3. **P2：消息 + 我的 + 次级页 + 完整状态。** 完成组件一致性和全页面适配。

每阶段都包含深色、大字体和异常状态，不把它们留到最后。保持原功能 ID、导航路由和本地设置；界面重设计不要求换技术栈或扩充学校接口。

## 12. 设计验收清单

后续实现至少提供以下对照图：今日/课表/查询/我的四页浅深色各一张，成绩/考试/余额/消息详情各一张，以及未登录、空数据、缓存失败、非空数据未支持、大字体代表场景。截图使用明确的虚构样本，不包含真实学生信息。

- [ ] 320dp、字体 2 倍下关键动作可点击，课程名和金额无布局溢出。

### 文档之间需明确的取舍

1. V1 将门户日程列为目标页面，数据交接明确它尚未进入完成契约：V2 默认面板不展示为可用能力。
2. V1 课程格建议展示节次起止时间，但 A06 当前没有此信息：课程实例自己的可信时间仍可显示，节次轴不反推通用作息。

6. 非空考试字段受 showkeys 控制：未允许展示的字段不呈现；仅对允许显示但缺值的字段使用“未提供”，避免误导为未公布。
